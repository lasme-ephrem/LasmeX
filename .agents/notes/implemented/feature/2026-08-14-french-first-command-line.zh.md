# Agent Note: 法语优先的命令行

Status: implemented

[English](2026-08-14-french-first-command-line.md) | 中文

## 问题

LasmeX 定位为法语优先产品，但启动器、Web 服务器和 headless 入口仍以英语显示 Commander 标题、用法示例、校验错误和 headless 人设。只翻译顶层描述会让常见启动失败和子命令帮助继续混用语言。

## 决定

共享命令行包提供 `configureFrenchCommand()`，统一配置 Commander 标题和错误前缀，同时保持稳定的命令名和选项标志不变。LasmeX 启动器以及 Web、headless 入口分别提供法语的用户描述、示例和校验消息。

headless bundle 还使用法语优先的 LasmeX 人设，并用 `LasmeX` 作为致命运行时诊断的前缀。Provider 标识、环境变量名、子进程输出以及外部工具拥有的诊断保持不变，因为翻译这些内容会改变接口或掩盖来源。

## 影响

源码和构建产物的启动路径现在具有一致的法语帮助与第一方启动错误。新的第一方命令必须应用共享配置，并在自身解析入口提供法语描述。测试覆盖本地化错误和构建后命令帮助，避免源码行为掩盖打包回归。

## 考虑过的替代方案

| 替代方案 | 拒绝原因 |
|---|---|
| 只翻译根级 `lasmex --help` 输出 | Web 和 headless 用法、子命令错误以及直接执行 bundle 时仍会显示英语。 |
| 把命令名和选项标志也改成法语 | 这会让脚本更难共享，并把本地化变成不稳定的命令接口。 |
| 翻译所有下游诊断 | Provider 和外部工具错误需要保持可搜索，并能归因于真正的所有者。 |
