# Agent Note: LasmeX Code 作为默认 Agent 预设

Status: implemented

[English](2026-08-14-lasmex-code-default-preset.md) | 中文

## 问题

已交付的 Code Mode 组合通过一个 TypeScript SDK 呈现完整的编码工具目录，已经能够减少模型往返；但它的通用身份、中文文件元数据和可选位置并不能定义 LasmeX 的默认 Agent 体验。重新实现调度器或工具只会复制成熟行为，而不会让产品获得更明确的执行策略。

## 决策

内置 `lasmex-code` 预设是 Web 产品的默认 Agent 组合。它取代内置 `code` 标识符，并保留该预设的能力行、隔离服务、压缩、规划、委派、目标、技能和 Code Mode 呈现。模型只看到 `run_code`；作用域工具注册表仍保留底层目录，用于生成 SDK 和执行调用。

该预设提供法语 persona：标识 LasmeX Code，插值所选模型与会话工作区，要求修改前检查仓库，按风险验证结果，并规定最终回复需要报告的内容。对于不可逆操作以及无法从上下文确定的重要产品选择，它要求先获得确认。这些指令指导模型；权限仍由宿主的沙箱和审批插件强制执行。

内置预设的名称和说明通过 Web locale 目录解析为法语、英语和中文。原始 `preset.yml` 文件使用法语，因此非 Web 名单消费者也能获得 LasmeX 产品文案。`standard`、`minimal` 和 `cordis` 仍可选择，已存储的用户默认值继续覆盖部署默认值。

## 验证

内置 Web 组合测试固定精确的预设名单、`lasmex-code` 默认值、Code Mode 呈现、底层 SDK 目录，以及它与相邻原生会话之间的隔离。无密钥的 `lasmex-code.snapshot.ts` 场景启动真实 Web 组合，挂载未指名的默认预设，渲染其提示词变量，并快照法语 persona、`run_code` 呈现、代表性 SDK 能力和底层工具数量。客户端 locale 测试固定内置预设的本地化映射。

## 曾考虑的替代方案

- **实现 LasmeX 专用 Agent 循环。** 否决，因为现有循环、工具注册表和 Code Mode 呈现器已经提供所需执行机制；仅为提示词策略分叉循环会产生一套平行生命周期。
- **继续以标准模式作为部署默认值。** 否决，因为 LasmeX Code 会继续只是一个可选的上游式模式，而不是新用户实际评估的产品行为。
- **只在用户可写的预设根目录中创建 LasmeX Code。** 否决，因为产品默认值必须能够从内置组合复现，不能依赖可变的机器状态。

## 后果

新建且未指名预设的会话使用 Code Mode 和法语执行 persona；现有会话与显式预设选择保留其记录的组合。预发布阶段使用已移除 `code` 标识符记录的会话不会获得兼容别名。更适合原生工具调用的模型仍可选择 `standard`；在预设继承机制出现之前，维护两种呈现需要保留一份重复组合。
