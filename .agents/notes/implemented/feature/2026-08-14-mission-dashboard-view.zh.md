# Agent Note: Mission 是由投影支持的会话视图

Status: implemented

[English](2026-08-14-mission-dashboard-view.md) | 中文

## 问题

运行仪表板必须在实时更新、历史分页、重新加载和 Code Mode 中保持准确，同时不能暴露会话内容，也不能在 React 中重建持久事实。缺少可选能力还必须与有效的零值或空值区分开。

## 决策

`lasmex-client-ui-mission` 以顺序 `5` 注册会话作用域的 `mission` 会话视图。它同时读取现有的 `goal`、`plan`、`permissions`、`todos`、`sessionStats`、`tokenUsage` 投影和 `missionActivity` 投影。React 不拥有业务 store，也不进行事件折叠。实时状态只读取 Session 快照中的运行状态、等待数量、队列数量、打开状态、移除状态和分页字段。编排卡片从现有 Session 列表 store 读取直接子智能体目录、子项摘要和后台任务视图；它只打开带有目录派生直接父地址的子项。

该视图绝不读取会话节点、消息、chunk、推理、请求 header 或工具结果。它只显示精确的验证命令和后台任务标签，因为 Host API 有意为人工界面公开这些有界运行记录。缺少投影会产生不可用状态；已经存在的 null 或空值会产生领域特定的中性状态。缺少子项和任务行会产生中性空状态，而目录和生命周期标签只映射精确的已发布状态。普通 Session 分页回调加载更早历史记录，而不会改变全日志总数。

法语是完整的主要产品词典，并提供键完全相同的英语和简体中文词典。语义化 section、definition list、文本状态标签、礼貌播报的状态区域、可见焦点和键盘可操作的分页按钮构成无障碍基线。

## 考虑过的替代方案

**折叠已加载的会话窗口。** 分页和压缩会使窗口不完整，因此加载更早页面时状态和总数会变化。

**把完整 Session 快照传给仪表板辅助函数。** 尽管该功能不需要会话字段，这会让展示代码仍然可以访问它们。

**用零表示缺少能力。** 零表示已组合的投影没有观察到事件；缺少表示部署没有提供该能力。合并两者会造成误导。

## 测试

包测试覆盖完整和缺失投影、法语渲染、状态优先级、安全字段选择、编排元数据和导航、中性空状态、分页、插槽顺序和生命周期、语言键一致性，以及空 Node half 行为。组装后的 Web 回放覆盖 Code Mode 能力活动、历史分页、重新加载持久性和稳定的无障碍快照。

## 后果

Mission 仍是可替换的客户端插件，并且不会引入新的客户端状态权威。装配必须挂载每个需要的 Host 投影。包含此视图的第一个 GUI pull request 必须附上从稳定的组装服务器和真实模型流程录制的 GIF。
