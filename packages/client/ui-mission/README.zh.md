# lasmex-client-ui-mission

[English](README.md) | 中文

这是一个仅浏览器的消费方，在顺序 `5` 注册 `mission` 会话视图。仪表板把 `goal`、`plan`、`permissions`、`todos`、`sessionStats`、`tokenUsage` 和 `missionActivity` 投影与实时会话及编排指标组合起来。法语、英语和简体中文词典一起交付；当前客户端语言决定显示文案。

## 组合

在 Host 上使用显式的验证工具、命令模式和保留数量配置挂载 `lasmex-session-mission`，再把本包挂载到 Web 客户端清单中。该视图等待 `conversation.view` 插槽声明，并随其 Cordis fiber 注销。

缺少投影会显示为不可用。已经存在但为空的目标、待办列表、能力列表或验证列表分别使用诚实的中性状态。计数绝不会从分页会话窗口中推测。历史记录操作使用普通 Session 分页回调，而全日志投影值在加载更早页面时保持稳定。

编排卡片读取 Session 列表 store 已发布的直接子智能体目录、会话摘要和后台任务视图。健康的目录子项可以通过精确的父子地址打开。只有摘要的子项在目录到达期间仍可识别，但不会获得推测的模式或导航操作。空、加载、错误、诊断、活动、模式和任务生命周期标签只映射客户端接口中已有的状态。

## 隐私与无障碍

组件只读取投影值、会话的生命周期、等待数量、队列数量和分页字段，以及浏览器安全的子智能体、会话摘要和后台任务元数据。它不读取会话节点、消息、流式 chunk、推理、请求 header 或工具结果。精确的已配置验证命令和后台任务标签保持可见，因为它们是 Host API 为人工界面显式发布的运行字段。

仪表板使用带无障碍标题的 section、用于标签和值配对的 definition list、每个颜色状态旁的文本标签、礼貌播报的实时状态，以及可通过键盘聚焦的历史记录按钮。样式只使用共享 `--dsw-*` token。

## 模型体验

### 请求上下文和条件

#### 模型看到的内容

什么也看不到。`mission` 视图是展示消费方，不贡献提示词、消息、工具 schema 或会话事件。

#### Token 影响

直接和间接模型 token 均为零。

#### KV Cache 影响

不会影响 KV 缓存。

## 已知限制和延后工作

- 自定义验证协议需要先有 Host 投影适配器，本视图才能显示其结果。
- 产品行为 GIF 会延后到组装后的 LasmeX Web 服务器足够稳定、能够录制真实流程时制作。
